# PWA 계산기

순수 HTML / CSS / JavaScript로 만든 설치형(PWA) 계산기입니다. 빌드 도구가 필요 없습니다.

## 기능

- 사칙연산(+ − × ÷), 소수점, `C`(전체 지우기), `⌫`(한 글자 지우기), `±`(부호 바꾸기)
- `=` 를 연속으로 누르면 직전 계산 반복 (예: `2 + 3 = =` → 8)
- 0으로 나누면 "0으로 나눌 수 없습니다" 표시 → 아무 숫자나 누르면 다시 시작
- 키보드 입력 지원
- 휴대폰 화면 대응, 다크 모드 자동 적용
- 설치 후 오프라인에서도 동작
- 계산은 `eval()` 없이 직접 구현

> 참고: 일반 휴대폰 계산기처럼 **누른 순서대로** 계산합니다.
> `2 + 3 × 4 =` 는 `(2 + 3) × 4 = 20` 이 됩니다.

### 키보드

| 키 | 동작 |
|---|---|
| `0`–`9` | 숫자 |
| `+` `-` `*` `/` | 연산자 (`x` 도 곱하기) |
| `.` 또는 `,` | 소수점 |
| `Enter` 또는 `=` | 계산 |
| `Backspace` | 한 글자 지우기 |
| `Esc` / `Delete` / `C` | 전체 지우기 |

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 (버튼 배치) |
| `style.css` | 디자인, 다크 모드, 휴대폰 대응 |
| `app.js` | 계산 로직, 키보드 입력, 서비스 워커 등록 |
| `manifest.webmanifest` | 앱 이름·아이콘 등 설치 정보 |
| `sw.js` | 서비스 워커 (오프라인 캐시) |
| `icons/` | 앱 아이콘 |

## 내 컴퓨터에서 실행해 보기

`index.html` 을 더블클릭하면 계산기 자체는 동작하지만, **서비스 워커(설치·오프라인)는 `file://` 에서 동작하지 않습니다.**
간단한 웹 서버로 열어야 합니다. Node.js 가 설치되어 있다면 이 폴더에서:

```powershell
npx serve .
```

그다음 화면에 나온 주소(예: http://localhost:3000)를 브라우저로 여세요.

## GitHub Pages 배포

1. GitHub 에서 `pwa-calculator` 라는 이름으로 새 저장소를 만듭니다.
2. 이 폴더에서 아래 명령을 실행합니다 (`사용자이름` 부분을 바꾸세요):
   ```powershell
   git remote add origin https://github.com/사용자이름/pwa-calculator.git
   git push -u origin main
   ```
3. 저장소의 **Settings → Pages** 에서 Source 를 `Deploy from a branch`, Branch 를 `main` / `/ (root)` 로 선택 후 Save.
4. 1~2분 뒤 `https://사용자이름.github.io/pwa-calculator/` 에서 열립니다.

모든 경로가 `./` 상대경로라서 하위 폴더 주소에서도 그대로 동작합니다.

### 앱으로 설치하기

- **안드로이드 / PC 크롬·엣지**: 주소창 오른쪽의 설치 아이콘, 또는 메뉴 → "앱 설치"
- **아이폰(사파리)**: 공유 버튼 → "홈 화면에 추가"

## 수정 후 다시 배포할 때 ⚠️

서비스 워커가 파일을 기기에 저장해 두기 때문에, 수정한 내용이 바로 안 보일 수 있습니다.
파일을 고친 뒤에는 **`sw.js` 맨 위의 `CACHE_VERSION` 을 `'v1'` → `'v2'` 처럼 올려서** 함께 올려 주세요.
새 파일을 추가했다면 `sw.js` 의 `APP_FILES` 목록에도 넣어 주세요.
